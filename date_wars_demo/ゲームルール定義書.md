# 日付対戦 ゲームルール定義書

**文書バージョン：** 0.4（ドラフト）  
**ゲーム形式：** 2人対戦・ターン制  
**対象プラットフォーム：** Webブラウザ、Android、iOS

## 1. ゲーム概要

本ゲームは、特定の年月のカレンダーを盤面として使用し、2人のプレイヤーが同時に日付を選択するターン制対戦ゲームである。

各プレイヤーは、対戦前に曜日別の得点倍率を設定する。

各ターンでは、両プレイヤーが選択した日付を公開し、日付の大小関係と特殊ルールによって勝者を決定する。勝者には、選択した日付の曜日に設定された得点倍率に応じたスコアを加算する。

対戦終了後、最後に残る日付の予想ボーナスを加算し、最終取得ポイントと所定の優先順位に従って勝敗を決定する。

ただし、両プレイヤーが日付を選択しないターンが5回連続した場合は、強制的に引き分けとしてゲームを終了する。

## 2. 対戦モード

| 対戦モード | 年月の決定方法 | 日付選択の制限時間 |
|---|---|---|
| ランダムマッチ | サーバーがランダムに決定 | 20秒 |
| レートマッチ | サーバーがランダムに決定 | 20秒 |
| プライベートマッチ | ルーム作成者が指定またはランダムを選択 | 5秒、10秒、20秒、60秒、無制限 |

プライベートマッチでは、ルーム作成時に年月の決定方法と制限時間を設定する。

選択された設定は、対戦開始後に変更できない。

## 3. 曜日別得点倍率の設定

### 3.1 設定方法

各プレイヤーはマッチング前に、月曜日から日曜日までの7曜日に対して得点倍率を設定する。

設定値は以下の7種類とし、各値を重複なく1回ずつ割り当てる。

`-3、-2、-1、0、1、2、3`

曜日別得点倍率は、対戦開始後に変更できない。

### 3.2 得点計算

日付スコアの基本値は、当面の間「1」とする。

勝者が選択した日付の曜日に設定されている倍率を用いてスコアを計算する。

**計算式**

`獲得スコア = 日付基本スコア × 勝者の日付に対応する曜日倍率`

日付基本スコアは将来的に変更可能な設定値とする。

| 曜日倍率 | 勝利時の獲得スコア |
|---:|---:|
| +3 | +3ポイント |
| +2 | +2ポイント |
| +1 | +1ポイント |
| 0 | 0ポイント |
| -1 | -1ポイント |
| -2 | -2ポイント |
| -3 | -3ポイント |

倍率が負数の場合、勝利したプレイヤーのスコアを減算する。敗者のスコアは変更しない。

倍率が0の場合はスコアを変更しないが、勝利回数には含める。

## 4. 年月の決定

### 4.1 ランダムマッチ・レートマッチ

対戦成立後、サーバーが対象年月をランダムに決定する。

対象年月の決定処理はサーバー側で行う。

### 4.2 プライベートマッチ

ルーム作成者は、以下のいずれかを選択する。

- **年月指定：** 対戦に使用する年と月を指定する。
- **ランダム：** サーバーが年月をランダムに決定する。

ランダムの場合、サーバーが設定済みの対象年範囲から年月を選択する。

対象年の範囲とランダム選択の分布は別途設定する。

### 4.3 カレンダーの公開

年月決定後、対象月のカレンダーを両プレイヤーに公開する。

対象月に実在しない日付は選択対象に含めない。

## 5. 最終日付の予想

### 5.1 予想の選択

年月が公開された後、各プレイヤーはゲーム終了時に残ると予想する日付を1つ選択する。

選択肢は以下の2種類とする。

- 特定の日付を指定する。
- 「日付が残らない」を指定する。

予想は一度確定したら変更できない。予想内容はゲーム終了まで相手に公開しない。

### 5.2 予想ボーナス

通常のゲーム終了時に予想が的中していた場合、最終取得ポイントに5ポイントを加算する。

5ポイントは暫定値であり、将来的に変更できる設定値とする。

| ゲーム終了時の状態 | 的中条件 |
|---|---|
| 日付が1日残った | 残った日付を予想している |
| 日付が残らなかった | 「日付が残らない」を予想している |

予想が外れた場合、ボーナスは加算しない。

両プレイヤーが的中した場合は、両者にそれぞれ5ポイントを加算する。

予想ボーナスは最終取得ポイントにのみ加算し、ターンごとの獲得スコア、勝利回数、最大プラス得点には含めない。

第9章の連続スキップ上限により引き分けとなった場合は、通常の最終日付予想の的中判定およびボーナス加算を行わない。

## 6. ターンの進行

1ターンは「日付選択ターン」と「公開ターン」で構成する。

### 6.1 日付選択ターン

両プレイヤーは、選択可能な日付からそれぞれ1つを選択する。

両者の選択が確定するまでは、選択内容を相手に公開しない。

過去のターンで消費された日付は選択できない。

同じターンに両者が同じ日付を選択することは許可する。

日付選択には、対戦モードに応じた制限時間を適用する。

### 6.2 公開ターン

両プレイヤーの選択が確定した時点で、選択内容を同時に公開する。

両者が日付を選択している場合は、第7章の勝敗判定ルールに従い、勝者と獲得スコアを確定する。

制限時間切れによる処理は、第9章に従う。

### 6.3 日付の消費

公開ターン終了後、選択済みとなった日付を選択不可にする。

両者が同じ日付を選択した場合、その日付は1つだけ消費する。

日付の消費処理後、選択可能な日付の残数を確認する。

- 残り2日以上：次のターンへ進む。
- 残り1日以下：ゲームを終了する。

両者とも日付を選択しなかった場合は、日付を消費せず、そのターンをスキップして次のターンへ進む。ただし、連続スキップ回数が5回に達した場合は、第9章に従って引き分けで終了する。

### 6.4 連続スキップ回数の管理

サーバーは、両プレイヤーが日付を選択しなかったことによってスキップされたターンの連続回数を管理する。

- 両プレイヤーが日付を選択しなかった場合：連続スキップ回数を1増加させる。
- 少なくとも一方のプレイヤーが日付を選択した場合：連続スキップ回数を0に戻す。
- 連続スキップ回数が5回に達した場合：直ちにゲームを引き分けで終了する。

ゲーム開始時の連続スキップ回数は0とする。

## 7. 勝敗判定ルール

両プレイヤーが異なる日付を選択した場合、以下の優先順位で勝者を決定する。

### 優先順位1：月末日と1日の対戦

一方が対象月の最終日、もう一方が1日を選択した場合、1日を選択したプレイヤーを勝者とする。

このルールは、プレイヤーの位置に関係なく適用する。

例：31日と1日の対戦では、1日を選択したプレイヤーが勝利する。

### 優先順位2：同一グループの最小日付と最大日付の対戦

日付を5日単位で分類する。ただし、31日を含むグループを第六グループとする。

| グループ | 日付 |
|---|---|
| 第1グループ | 1〜5日 |
| 第2グループ | 6〜10日 |
| 第3グループ | 11〜15日 |
| 第4グループ | 16〜20日 |
| 第5グループ | 21〜25日 |
| 第6グループ | 26〜31日 |

対象月に存在しない日付は含めない。第六グループは、対象月に実在する26日から月末日までの日付で構成する。

両プレイヤーの選択日付が同一グループに属し、そのグループの最小日付と最大日付が選択されていた場合は、最小日付を選択したプレイヤーを勝者とする。

例：1日と5日の対戦では、1日を選択したプレイヤーが勝利する。

例：26日と31日の対戦では、26日を選択したプレイヤーが勝利する。ただし、月末日と1日の対戦には優先順位1を適用する。

同一グループ内であっても、最小日付と最大日付の組み合わせでなければ、通常ルールを適用する。

### 優先順位3：日付の大小比較

前述の特殊ルールに該当しない場合は、数値の大きい日付を選択したプレイヤーを勝者とする。

### 7.1 同じ日付が選択された場合

両プレイヤーが同じ日付を選択した場合、そのターンの勝者は決定しない。

両者のスコアおよび勝利回数は変更せず、日付を1つ消費して次のターンへ進む。

## 8. 得点と対戦中の記録

### 8.1 ターンごとのスコア

勝者には第3章の計算式に従ってスコアを加算・減算する。

敗者のスコアは変更しない。

同じ日付が選択されたターンでは、両者のスコアを変更しない。

### 8.2 勝利回数

各プレイヤーについて、日付対戦で勝者となった回数を記録する。

獲得スコアが正数、0、負数のいずれであっても、勝者となった場合は勝利回数を1増加させる。

同じ日付が選択されたターンと、両者が日付を選択しなかったターンは、いずれのプレイヤーの勝利回数にも含めない。

### 8.3 最大プラス得点

各プレイヤーについて、日付対戦の1回の勝利で獲得した正のスコアの最大値を記録する。

正のスコアを一度も獲得していない場合は0とする。

予想ボーナスおよび制限時間切れによる追加ポイントは、最大プラス得点の計算対象に含めない。

## 9. 制限時間

### 9.1 制限時間の設定

| 対戦モード | 制限時間 |
|---|---|
| ランダムマッチ | 20秒 |
| レートマッチ | 20秒 |
| プライベートマッチ | 5秒、10秒、20秒、60秒、無制限から選択 |

制限時間はプライベートルームの設定として保存する。

無制限の場合はタイムアウトによる処理を行わない。

### 9.2 制限時間の対象

制限時間は、対戦開始後にプレイヤーの入力が必要なフェーズ、すなわち最終日付の予想と各ターンの日付選択に適用する。

曜日別得点倍率の設定とマッチング待機には、この制限時間を適用しない。

### 9.3 制限時間切れ時の処理

日付選択ターンにおいて制限時間が切れた場合は、以下のルールで処理する。

**片方のプレイヤーだけが日付を選択している場合**

1. 日付を選択しているプレイヤーの選択日付を選択済みとする。
2. 日付を選択しているプレイヤーのスコアに、固定で3ポイントを加算する。
3. 選択済みとなった日付を選択不可にする。
4. 通常の日付対戦による勝敗判定と曜日別得点計算は行わない。
5. 連続スキップ回数を0に戻す。
6. 次のターンへ進む。ただし、選択可能な日付が1日以下になった場合はゲームを終了する。

追加される3ポイントは曜日別得点倍率とは独立した固定ポイントとする。

この処理による追加ポイントは、日付対戦での勝利とは扱わないため、勝利回数には含めない。

**両方のプレイヤーが日付を選択していない場合**

1. 両プレイヤーに、制限時間内に選択が行われなかった旨を通知する。
2. 日付を消費しない。
3. スコアおよび勝利回数を変更しない。
4. 連続スキップ回数を1増加させる。
5. 連続スキップ回数が5回に達した場合は、ゲームを引き分けで終了する。
6. 5回に達していない場合は、そのターンをスキップして次のターンへ進む。

無制限の場合は、制限時間切れによる上記の処理は発生しない。

最終日付の予想フェーズで制限時間が切れた場合の処理は、別途確定する。

### 9.4 連続スキップによる強制終了

両プレイヤーが日付を選択しなかったターンが5回連続した場合、サーバーは対戦を引き分けとして終了させる。

この場合、現在のスコアや勝利回数に関係なく、最終結果を引き分けとする。

通常の最終日付予想の的中判定、予想ボーナスの加算、および最終取得ポイントに基づく勝敗判定は行わない。

それまでに確定した各プレイヤーのスコアやターン履歴は、対戦記録として保存する。

## 10. 通信切断時の処理

対戦中に一方のプレイヤーの通信切断が検知された場合、切断した側の敗北として処理する。

通信切断したプレイヤーには、再接続による対戦復帰を認めない。

サーバーは切断を検知した後、勝敗を確定し、対戦結果を保存したうえで、接続中の相手プレイヤーに結果を通知する。

切断が発生したターンの未確定な選択については、勝敗判定およびスコア加算を行わず、切断による敗北を優先する。

ただし、サーバー全体の障害など、どちらのプレイヤーにも帰責できない障害については、プレイヤーの通信切断による敗北とは区別して扱う。

## 11. ゲーム終了と最終勝敗判定

以下のいずれかに該当した場合、ゲームを終了する。

- 選択可能な日付が1日以下になった場合。
- 連続スキップ回数が5回に達した場合。

連続スキップ回数が5回に達した場合は、第9.4項に従い、他の条件に優先して引き分けとして終了する。

通常の終了条件を満たした場合は、最終日付の予想を判定し、的中したプレイヤーにボーナスを加算して、最終取得ポイントを確定する。

最終取得ポイントは、日付対戦で発生したスコアの合計、制限時間切れによる追加ポイント、および予想ボーナスの合計とする。

### 11.1 通常終了時の勝敗判定順位

以下の順番で比較する。

1. **最終取得ポイント**が高いプレイヤーを勝者とする。
2. 最終取得ポイントが同じ場合、**勝利回数**が多いプレイヤーを勝者とする。
3. 勝利回数も同じ場合、**最大プラス得点**が高いプレイヤーを勝者とする。
4. 以上の条件がすべて同じ場合、引き分けとする。

### 11.2 対戦結果の確定

勝敗判定後、サーバーは対戦結果を確定し、両プレイヤーに結果を通知する。

対戦履歴には、少なくとも以下の情報を保存する。

- 対戦IDおよび対戦モード
- 対戦年月
- 各プレイヤーの曜日別得点倍率
- 各ターンの選択日付と勝敗
- 各ターンの獲得スコア
- 制限時間切れによる追加ポイント
- 各プレイヤーの最終取得ポイント
- 各プレイヤーの勝利回数と最大プラス得点
- 各プレイヤーの予想内容と的中結果
- 対戦の最終結果
- 連続スキップ回数
- タイムアウト、連続スキップ、通信切断による終了の場合、その終了理由

## 12. 今後確定が必要な事項

以下は未確定として扱う。

1. ランダム年月の対象年範囲と選択分布。
2. 最終日付の予想フェーズで制限時間が切れた場合の処理。
3. 通信切断を検知する具体的な条件と判定時間。
4. プライベートマッチの年月指定を、ルーム作成者のみ可能とするか。
5. レートマッチでのレート計算式と、プライベートマッチの結果をレートに反映するか。
6. マッチング待機中やゲーム開始前に退出した場合の処理。
